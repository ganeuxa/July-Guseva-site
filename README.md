# Лендинг «Юлия Гусева — кадровое сопровождение»

Одностраничный адаптивный сайт-визитка специалиста по кадровому
сопровождению. Чистый HTML5 + CSS3 + немного ванильного JavaScript.
Без сборщика, фреймворков, backend, API и форм — готов к размещению
на любом статическом хостинге.

## Запуск

Проекту не нужен интернет и сборка. Достаточно отдать файлы любым
статическим сервером. Например, из корня проекта:

```bash
python -m http.server 8000
# затем открыть http://127.0.0.1:8000/
```

Можно также просто открыть `index.html`, но локальный сервер
предпочтительнее: браузеры строже относятся к загрузке модульного
JavaScript и шрифтов по `file://`.

## Структура проекта

```
/
├── index.html              — единственная страница сайта
├── css/
│   ├── variables.css       — дизайн-система (цвета, шрифты, отступы, радиусы)
│   ├── fonts.css           — локальные @font-face (Spectral, IBM Plex Sans/Mono)
│   ├── base.css            — сброс, типографика, контейнер, доступность
│   ├── components.css      — кнопки, «таблетки», иконки, карточки, шапка/навигация
│   ├── sections.css        — стили секций (mobile-first)
│   └── responsive.css      — медиазапросы и мобильное меню
├── js/
│   └── main.js             — мобильное меню + подсветка активного пункта (ES-модуль)
├── assets/
│   ├── fonts/              — WOFF2-подмножества (cyrillic + latin)
│   ├── logo/logo.svg       — логотип (используется и как favicon, и в блоке контактов)
│   └── images/
│       ├── placeholders/   — временные SVG-заглушки под фотографии
│       └── certificates/   — временные SVG-заглушки под дипломы/сертификаты
├── original/               — исходные экспортированные макеты (НЕ используются сайтом)
└── README.md
```

### Исходные макеты

В папке `original/` лежат три экспортированных дизайн-макета:

* `Юлия Лендинг ПК.html` — **основной референс дизайна (десктоп)**;
* `Юлия Лендинг Платшетка.html` — планшет (референс адаптации);
* `Юлия Лендинг Мобилка.html` — мобильная версия (референс адаптации).

Эти файлы — только визуальные референсы (реальная разметка была спрятана
внутри bundler-скрипта). Итоговый сайт (`index.html`) от них не зависит.
**Приоритет при любых расхождениях — за десктопным макетом.**
Такие же копии остались и в корне проекта — их можно удалить, сайту
они не нужны.

Заменяя файл, поправьте атрибут `src` (и по возможности `width`/`height`)

используйте WebP/AVIF, задавайте размеры и оставляйте `loading="lazy"`
для изображений ниже первого экрана (главный портрет грузится сразу).

### Контактные данные

В исходных макетах реальных контактов не было — стоят очевидные
плейсхолдеры. Замените их в секции «Контакты» и в шапке `index.html`
(все места помечены `TODO`):

* **Телефон** — `href="tel:+79000000000"` и текст `+7 900 000-00-00`
  (кнопка «Позвонить», строка «Телефон», иконка-телефон в шапке).
* **Email** — `href="mailto:email@example.ru"` и текст `email@example.ru`
  (строка «Email», иконка-конверт в шапке).
* **MAX** — кнопка «Опишите ситуацию в MAX» и иконка в шапке: подставить
  реальную ссылку вместо `href="#"` / `href="#contacts"`.
* **Telegram** — кнопка «Написать в Telegram» и иконка в шапке: подставить
  реальную ссылку.
* **Группа ВК** — строка «Группа ВК», заменить `https://vk.com/group`.
* **Политика конфиденциальности** — ссылка в подвале (`href="#"`).
* **Домен** — раскомментировать и заполнить `<link rel="canonical">`
  и при необходимости абсолютные пути в Open Graph.

## Адаптивность

Вёрстка mobile-first и резиновая (корректна и на промежутных ширинах).
Точки переключения:

| Ширина | Что меняется |
|--------|--------------|
| < 600px | одна колонка, всё вертикально |
| ≥ 600px | боли/отзывы — 2 колонки, статистика героя — 3 колонки |
| ≥ 768px | 2 колонки в герое, «Обо мне», кейсах, услугах и контактах |
| ≥ 960px | полноценное горизонтальное меню в шапке (ниже — бургер) |
| ≥ 1024px | боли/услуги/кейсы/отзывы — 3 колонки, статистика — 4 колонки |
| ≥ 1280px | фиксированные пропорции колонок как в десктопном макете |

## Технические заметки

* Шрифты подключены локально (WOFF2), только нужные начертания и
  подмножества cyrillic + latin. Google Fonts не используется.
* JavaScript нужен только для мобильного меню и подсветки навигации.
  Без JS сайт остаётся читаемым; на десктопе меню видно всегда.
* Учтены базовые требования доступности: один `<h1>`, семантические
  теги, `:focus-visible`, управление меню с клавиатуры (Esc), `aria-*`
  у бургера, `prefers-reduced-motion`.
* Контактный блок статический — формы, анкеты, отправки данных,
  backend, API и webhook отсутствуют по условию.
